# Technical debt

Known shortcuts and deferred work, recorded honestly so nobody rediscovers them the hard way. Each item says why it exists and what would retire it. The GrowTrades platform's own list is archived in [`archive/growtrades-platform/technical-debt.md`](archive/growtrades-platform/technical-debt.md).

| Item                                                                                                                                                    | Why it exists                                                                                                                                                                                                  | Retire it by                                                                                                    |
| ------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| `.astro` files are not linted by ESLint or formatted by Prettier                                                                                        | Both need plugins (`eslint-plugin-astro`, `prettier-plugin-astro`) outside the approved dependencies (spec U.6)                                                                                                | `scripts/check-design.mjs` covers the design bans; add the plugins only with an ADR                             |
| pnpm 9 can leave `@emnapi/core` and `@emnapi/runtime` uninstalled after incremental installs, which makes `astro check` ask to install `@astrojs/check` | pnpm keeps packages it once skipped as platform-specific optional dependencies in `node_modules/.modules.yaml`, even after another package needs them; `@astrojs/astro2tsx` is WebAssembly-only and needs them | Delete `node_modules` and run `pnpm install` again (CI always installs fresh); an upgrade to pnpm 10 may fix it |
| Two Vite majors (wizard on Vite 5, site on Astro 7's Vite 8)                                                                                            | The wizard's build and tests are kept as they are (spec section 0, rule 2)                                                                                                                                     | Moving the wizard to the site's Vite major when there is a reason to touch its build                            |
| `tseslint.config()` is deprecated (an `astro check` hint)                                                                                               | The wizard's ESLint config uses it and the site's matches it                                                                                                                                                   | Moving both configs to ESLint's `defineConfig` in one change                                                    |
| The Sveltia CMS configuration has not been tried with a real sign-in                                                                                    | Signing in needs Josh's personal access token                                                                                                                                                                  | Josh opening `/admin` once after the first deploy; the build reports any file the CMS writes wrongly            |
| Below 360 px the compact "Start a conversation" button leaves the bar (it stays in the drawer)                                                          | At 320 px it cannot fit beside the name and the menu button without horizontal scroll, which spec O forbids                                                                                                    | Nothing, unless the name or label changes                                                                       |
| The tungsten accent has not been checked against stills from Josh's footage (spec E.2)                                                                  | No footage yet                                                                                                                                                                                                 | Comparing it when the footage arrives (Pass 8); only the `tungsten` token would change                          |
| Markdown images in MDX bodies are Astro's optimised `<img>` (WebP), not a `<picture>` with AVIF                                                         | Astro processes them before the paragraph override sees them (ADR-0041 addendum)                                                                                                                               | `<Figure>` in the body when AVIF matters; or a Sätteri plugin if `@astrojs/markdown-satteri` is approved        |
| The homepage research shelf takes the newest documents of any kind, `/research` only those of research entries                                          | Spec G.3 does not restrict the shelf, and the threshold's research answer promises "experiments" too                                                                                                           | Restricting `shelf` in `pages/index.astro` if Josh prefers research entries only                                |
| Turnstile is not exercised in the browser tests                                                                                                         | CI has no Turnstile keys, so the widget is off there; verification, hostname and action checks are unit-tested against recorded responses                                                                      | Cloudflare's documented test keys in a CI-only build, if the widget itself ever changes                         |
| The contact page's loading skeleton has the selector's shape; with `?intent=` the first screen is a question step                                       | The skeleton is static HTML and cannot know the answer stored in the browser                                                                                                                                   | Nothing unless the shift shows up in Lighthouse; both are a card of about the same height                       |
| The Make.com scenario, Turnstile and the Worker secrets are not set up                                                                                  | They need Josh's accounts (`docs/deployment.md` steps 4 to 6, `docs/make-com.md`)                                                                                                                              | Josh doing those steps; until then messages are stored and wait in D1                                           |
| The SCB site's quote heading is dark on dark, and three of its project images (`/images/placeholder-*.jpg`) never existed                               | Gaps in the SCB site itself, shown as they are in the demo (ADR-0044)                                                                                                                                          | Fixing them in the SCB site's own repository, then rebuilding the demo                                          |
| The footage loop has not run in a browser test                                                                                                          | Its decisions (reduced motion, Save-Data, slow connections, pausing off screen) are unit-tested; the footage arrived on 7 October 2026                                                                         | A browser test on /music for pausing off screen and for Save-Data                                               |
| The footage loop is 6 seconds long                                                                                                                      | Josh's graded clip is 6 seconds; spec K.3 asks for 8 to 15, so `media:video` now accepts 5                                                                                                                     | A longer clip from the same shoot, encoded with `pnpm media:video --name field`                                 |
| Player videos (the dissertation and the agentic prototype) have an AVIF poster only                                                                     | A video's `poster` attribute takes one URL, and the AVIF is a third of the JPEG, which kept the dissertation page inside its LCP budget                                                                        | Nothing in current browsers; an older browser shows the player without its still                                |
| The homepage and the GrowTrades case study are within 50 ms of the 2.0 s LCP budget in Lighthouse                                                       | Lazy images close to the top start before the first paint, and Lighthouse counts them                                                                                                                          | Lighter images near the top of those pages if a new one is added there; CI fails first if the budget is crossed |
| The Content Security Policy has no reporting endpoint                                                                                                   | A meta policy cannot be report-only, and there is no traffic before launch; the browser suite enforces the policy on every flow instead (ADR-0048)                                                             | A `report-to` endpoint on the Worker after launch, if an outside script is ever added                           |
| Lighthouse runs on the static build without the Worker's headers                                                                                        | LHCI's own static server serves `apps/site/dist` (ADR-0047)                                                                                                                                                    | Nothing for timings; headers and the policy are checked against `wrangler dev` in the browser tests             |
| Astro warns at build time that Shiki's highlighting is not CSP-compatible                                                                               | Shiki writes style attributes, which the policy allows (`style-src-attr`); Astro warns whenever a policy is set                                                                                                | Nothing; or Prism if code blocks ever need a stricter policy                                                    |
| Structured data is checked against an in-repository copy of the schema.org definitions, not Google's own tools                                          | Google's Rich Results Test and validator.schema.org need a public URL (ADR-0049)                                                                                                                               | Running them on the live pages after launch (`deployment.md` step 12)                                           |
| The site is also served at the `workers.dev` address                                                                                                    | The custom domain needs Josh's Cloudflare account                                                                                                                                                              | `deployment.md` step 11, once `joshlennon.com` serves the site                                                  |
| The default share image and icons are committed files                                                                                                   | Rendering them needs Chromium, which the deploy does not have (ADR-0049)                                                                                                                                       | Nothing; run `pnpm media:og` when the name or headline changes                                                  |
| `src/data/github.snapshot.json` is from a developer machine                                                                                             | The deploy refreshes it in its build, but the repository copy only changes when someone commits a fresh one                                                                                                    | Nothing needed; or commit a refreshed snapshot now and then                                                     |
